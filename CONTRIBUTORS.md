# Contributors

This file records the people who actively maintain or have made meaningful contributions to the project.

As the repository evolves into a reusable template, this file should remain lightweight and easy to update.

## Maintainers

Add the current maintainers here.

Example format:

| Name | Role | Notes |
| --- | --- | --- |
| TBD | Maintainer | Primary project owner |

## Contributors

Add contributors here after a meaningful contribution such as:

- implementing a feature
- fixing a bug
- improving build or tooling
- expanding tests
- improving documentation in a substantial way

Example format:

| Name | Contribution Area | Notes |
| --- | --- | --- |
| TBD | Initial scaffold | Project bootstrap |

## How To Add Yourself

Add yourself to this file when your contribution is substantial and merged or otherwise accepted into the project.

Suggested entry format:

| Name | Contribution Area | Notes |
| --- | --- | --- |
| Your Name | Docs, build, tests, feature area | Short description |

## Attribution Guidelines

- Keep entries short and factual.
- Prefer one row per person unless there is a strong reason to split roles.
- Update the existing row when a contributor returns with more work.
- Do not add entries for trivial drive-by edits unless maintainers want exhaustive tracking.

## Notes

This file is for human-readable contributor recognition. It does not replace commit history, release notes, or formal authorship records.
